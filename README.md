# Harpia FOSS — Identidade Visual

Este repositório reúne os elementos da identidade visual da **Harpia FOSS**, incluindo o símbolo, o logotipo, a paleta de cores e suas diferentes versões.

## Processo de criação

A concepção inicial da identidade visual contou com o auxílio de ferramentas de inteligência artificial, utilizadas durante a etapa de exploração de ideias e referências visuais. Por meio de diferentes interações, foram avaliadas possíveis representações da harpia, composições e combinações de cores.

As imagens geradas serviram exclusivamente como referências para a definição da proposta visual.

**Toda a vetorização foi realizada manualmente, sem utilização de inteligência artificial**, incluindo a construção das formas, o refinamento dos elementos e os ajustes necessários para a produção dos arquivos finais.

## Símbolo

O símbolo representa a cabeça de uma harpia (gavião-real) vista de frente. Sua composição utiliza formas geométricas e simetria bilateral, com elementos inspirados nas características da ave.

O desenho foi desenvolvido em formato vetorial, utilizando formas fechadas e preenchidas, sem traços (*strokes*). As curvas possuem poucos pontos de controle, facilitando a edição e a manutenção dos arquivos.

Os espaços entre as penas são preservados como parte da composição. A região do rosto possui um preenchimento branco independente (`Face`), garantindo sua visibilidade sobre diferentes fundos.

## Tipografia

O logotipo **HARPIA** utiliza letras maiúsculas, com peso elevado e características geométricas semelhantes às fontes Montserrat ExtraBold e League Spartan.

As letras foram convertidas em contornos vetoriais, dispensando a instalação de fontes para utilização dos arquivos.

A inscrição **FOSS** utiliza letras de menor peso, com espaçamento ampliado e alinhamento centralizado abaixo do nome.

## Paleta de cores

A paleta utiliza as cores da bandeira brasileira, acompanhadas de tons complementares para contornos, detalhes e aplicações.

| Cor          | Código HEX | Aplicação               |
| ------------ | ---------- | ----------------------- |
| Azul-marinho | `#0B1F3B`  | Contornos e logotipo    |
| Azul         | `#1E4DB7`  | Bico e peito            |
| Verde        | `#009E60`  | Plumagem                |
| Amarelo      | `#F2C11A`  | Plumagem e olhos        |
| Branco       | `#F4F6F8`  | Rosto, coroa e garganta |
| Cinza        | `#94A3B8`  | Textos complementares   |

## Versões

A identidade visual está disponível em três versões, destinadas a diferentes aplicações.

- **Colorida:** versão principal, que utiliza a paleta completa. Possui contorno branco para preservar a visibilidade dos elementos sobre fundos azul-marinho.
- **Monocromática:** utiliza uma única cor, sendo adequada para documentos, impressões e aplicações que exigem reprodução simplificada.
- **Invertida:** destinada a aplicações sobre fundos escuros, substituindo os elementos em azul-marinho por branco.

As versões monocromática e invertida preservam a mesma composição vetorial, diferenciando-se apenas pela distribuição das cores.
